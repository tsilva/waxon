# Domain Docs

This is a single-context repository.

## Before exploring

- Read root `CONTEXT.md`.
- Read the ADRs under `docs/adr/` that touch the area being changed.
- If either location is absent, proceed silently.

## Vocabulary

Use the canonical terms defined in `CONTEXT.md` in issue titles, specifications, tests, and implementation discussions. Avoid synonyms that the glossary explicitly rejects.

If a needed concept is absent, reconsider whether it belongs to the domain vocabulary or note the gap for `/domain-modeling`.

## Decisions

Surface any conflict with an existing ADR explicitly instead of silently overriding it.
